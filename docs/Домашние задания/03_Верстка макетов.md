# Верстка макетов на Vue

Необходимо реализовать разработанные ранее wireframe-макеты в виде веб-приложения с использованием **Vue.js**. Реализация должна воспроизводить структуру страниц, расположение функциональных блоков и навигационные переходы, предусмотренные макетами.

## Требования к реализации

Приложение должно быть разработано с использованием **Vue 3**. Для организации переходов между страницами рекомендуется использовать **Vue Router**.

Допускается использование любых средств стилизации (CSS, SCSS, Bootstrap, Tailwind CSS и др.).

### В приложении должны быть реализованы:

- шапка сайта (Header);
- меню навигации;
- основные функциональные блоки страниц;
- формы ввода данных (если предусмотрены макетами);
- кнопки и элементы управления;
- подвал сайта (Footer);
- переходы между страницами.

### Можно упустить:

- подключение серверной части и базы данных;
- авторизация пользователей на стороне сервера;
- адаптивная верстка;
- сложное визуальное оформление;


Допускается использование тестовых данных и текстовых заглушек.

## Минимальный набор страниц

Необходимо реализовать следующие страницы:

- Главная страница;
- Страница каталога (списка объектов);
- Страница детального просмотра объекта;
- Страница обратной связи (или личного кабинета).

## Требования к навигации

Необходимо обеспечить следующие пользовательские сценарии:

- переход с главной страницы в каталог;
- переход из каталога на страницу объекта;
- переход на страницу авторизации;
- возврат на главную страницу через меню навигации.

Переходы между страницами должны выполняться без перезагрузки страницы средствами **Vue Router**.

## Требования к структуре проекта

Рекомендуется выделить повторно используемые элементы интерфейса в отдельные компоненты:

- Header;
- Footer;
- Navigation Menu;
- Card (элемент каталога);
- Form (форма авторизации или обратной связи).

Страницы должны быть организованы в виде отдельных компонентов и размещены в каталоге `views`, а переиспользуемые элементы интерфейса — в каталоге `components`.

## Результат выполнения

В результате выполнения задания должно быть получено работающее одностраничное приложение (SPA), реализованное на Vue.js, соответствующее ранее разработанным wireframe-макетам и обеспечивающее навигацию между страницами.
