# Интеграция backend и frontend. MVP

Необходимо объединить ранее разработанный frontend на **Vue.js** с backend-частью проекта и подготовить минимально работоспособную версию приложения — **MVP**.

## Цель задания

Реализовать взаимодействие пользовательского интерфейса с серверной частью приложения: получение, отправку, изменение и удаление данных через API.

## Требования к реализации

В проекте должны быть реализованы:

- подключение frontend к backend API;
- получение данных с сервера и отображение их на страницах;
- отправка данных из форм на сервер;
- обработка успешных и ошибочных ответов;
- отображение состояний загрузки;
- базовая валидация форм;
- работа с реальными или тестовыми данными из backend;
- корректная навигация между страницами после выполнения действий.

## Минимальный функционал MVP

Необходимо реализовать не менее следующих сценариев:

- загрузка списка объектов из backend на странице каталога;
- открытие страницы детального просмотра объекта по данным из backend;
- создание нового объекта через форму;
- редактирование существующего объекта;
- удаление объекта;
- авторизация или регистрация пользователя, если это предусмотрено проектом;
- отправка формы обратной связи или работа с личным кабинетом.

## Требования к backend

Backend должен предоставлять API для работы с основными сущностями проекта.

Минимально должны быть реализованы:

- эндпоинт для получения списка объектов;
- эндпоинт для получения одного объекта по идентификатору;
- эндпоинт для создания объекта;
- эндпоинт для обновления объекта;
- эндпоинт для удаления объекта;
- эндпоинты для авторизации/регистрации, если они предусмотрены проектом.

## Результат выполнения

В результате должен быть подготовлен **MVP проекта** — минимально работоспособное приложение, в котором frontend и backend связаны между собой, а основные пользовательские сценарии выполняются через API.
